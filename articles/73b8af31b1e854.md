人間とは、怠惰で忘れっぽい生き物である。
作業時間を正確に記録することなんて、できやしない。

……と開き直ったところから生まれた、macOS のタイムトラッカーの話です。

稼働時間ベースで報酬が決まる業務委託の案件を受けることになりました。
これまでの案件は時間ベースの契約ではなかったので、稼働時間の報告とは無縁でした。
今回からは、正確な稼働時間と作業内容を毎月報告する必要があります。
忘れっぽい人間には、なかなか荷が重い話です。

既製のタイムトラッカーをいくつか試したのですが、要件に合うものが見つかりませんでした。
それなら作ってしまおうと、macOS のメニューバーに常駐するタイムトラッカー「TimeTracker」を自作しました。
この記事では、TimeTracker がどんなアプリで、何ができて、どんな人に向いているかを紹介します。

## TimeTracker とは

メニューバーからプロジェクトごとの作業時間を記録する、macOS 用のタイムトラッカーです。
記録はすべて Mac の中に保存され、アカウント登録も外部送信もありません。
MIT ライセンスの OSS として GitHub で公開しています。

https://github.com/HappyOnigiri/TimeTracker

![月ごとの作業時間を集計したダッシュボード画面](/images/73b8af31b1e854/dashboard.png)

対応環境は macOS 14 以降です。

## こんな人に向いています

- 業務委託やフリーランスで、案件ごとの稼働時間を報告・請求している人
- 複数の業務を掛け持ちしていて、どの仕事に何時間使ったか把握したい人
- タスクごとにかけた時間を、月末にまとめて集計したい人

逆に、チームでの共有やスマホとの同期が必要な場合には向いていません。
データはローカル保存のみで、クラウド同期の機能を持たないためです。
一人で完結する時間管理に割り切ったアプリです。

## 既製のツールではだめだったのか

最初から自作するつもりはありませんでした。
メニューバーで操作できることを条件に探して、Tim（Time Tracker for macOS）と Horium を試しています。

計測そのものは、どちらも問題ありませんでした。
つまずいたのはエクスポートです。
報告書に転記するには CSV などでの書き出しが必須なのですが、どちらも有料プランの機能でした。

課金する前にエクスポートの形式を確かめられず、報告書に使える形かどうか分かりませんでした。
課金しても出力した CSV が意図した形式でなければ整形する必要があると結局手間がかかってしまうかもしれない、と思うと手が止まりました。
UI も自分には操作しづらく、毎日触る道具としては気が進みませんでした。

Toggl Track はだいぶ良さそうでしたが、こちらもエクスポートは有料プランの機能でした。
時間の計測だけのために毎月 9 ドルを払い続けるのは、ちょっと前向きになれませんでした。

そして、エンジニアなのでつい思ってしまいます。
「これくらいなら作れそう」と。
AI エージェントのおかげで、アプリ開発のハードルは以前より大きく下がっています。
むしろ作ってしまえば毎月 9 ドルが浮いて、好きな機能を足せるというおまけまで付いてきます。
こうして自作に踏み切りました。

## 主な機能

### 計測はメニューバーで完結

![メニューバーからプロジェクトを選んで計測を開始する画面](/images/73b8af31b1e854/menu-bar.png)

メニューバーのアイコンからプロジェクトを選ぶだけで、計測が始まります。
止めるときも同じ場所からワンクリックです。
ウィンドウを探して切り替える必要がないので、作業の流れを邪魔しません。

### 複数プロジェクトを同時に計測できる

複数のプロジェクトのタイマーを、同時に動かせます。
「A 案件のビルド待ちに B 案件を進める」といった時間も、両方そのまま記録できます。

地味に見えて、これはタイムトラッカーでは珍しい機能です。
Toggl Track・Clockify・Harvest はいずれも、新しいタイマーを開始すると前のタイマーが止まる単一タイマー方式です。
同時計測が不要な場合は、設定でオフにできます。

### 「何をしたか」も一緒に残せる

![作業内容のメモ付きで時間記録が並ぶリスト画面](/images/73b8af31b1e854/records.png)

記録には作業内容のメモを付けられます。
時間だけの記録だと、月末に見返したとき何の作業だったか思い出せません。
メモは記録リストからも、後述の月間タイムラインからも追加・編集できます。

### 月ごとの集計と CSV 出力

ダッシュボードでは、プロジェクトごとの作業時間を月単位で集計して表示します。
集計結果は、日付ごとの稼働時間と作業内容をまとめた CSV で保存できます。

```csv:daily-work.csv
日付,稼働時間(H),作業内容
2026-07-02,6.25,"画面設計,実装"
2026-07-03,1.50,問い合わせ対応
2026-07-05,4.00,実装
2026-07-06,4.50,"画面設計,定例ミーティング"
```

このほか、作業ログの明細や作業内容別の集計も CSV に書き出せます。

私はこのアプリを 2 か月ほど使っていますが、月末の稼働報告はこの CSV を報告書に載せるだけです。
1 分で終わります。

### 細かいところ

- Mac へのログイン時に自動起動できます
- 表示言語は日本語・英語・簡体字中国語から選べます

## 「どうせ記録し忘れる」を前提にした設計

冒頭に書いたとおり、人間は怠惰で忘れっぽい生き物です。
いろいろな機能を作って後から気づいたのですが、このアプリのテーマは「忘れたあと」にありました。

既製のツールは、正確に記録し続けられることを前提にしているように見えます。
記録の手動修正はできるものの、それは何時から働いていたか覚えている前提です。
TimeTracker は逆です。
どうせ記録し忘れるのだから、気づいたときにできるだけ正確に補正できることを目指しています。

### 止め忘れたら、自動で止まる

一定時間操作がないと、タイマーは自動で停止します。
離席していた時間は記録から除外されるので、止め忘れはアプリが勝手に補正してくれます。
検知までの時間（初期値は 5 分）や、検知のオン・オフは設定から変えられます。

### 開始し忘れは、さかのぼって開始

作業に集中していると、「あ、計測し忘れてた」ということがあります。
そんなときは、メニューバーから「5 分前 / 10 分前 / 15 分前から開始」を選べます。
もっと前から忘れていた場合も、日時を指定してさかのぼれます。

この「N 分前から開始」は、調べた範囲ではほとんどのツールにありませんでした。
多くのツールは、タイマーを開始したあとに開始時刻を手動で編集する方式です。
ワンクリックで済むかどうかは、毎日のことなので意外と効いてきます。

### 翌日気づいても、PC が覚えている

一番困るのは、「昨日作業してた気がするけど、計測を忘れてた」というやつです。
何時から何時まで働いていたかなんて、翌日には覚えていません。

そこで TimeTracker は、PC がアクティブだった時間帯を自動で記録しています。
1 か月を一画面で見渡せる月間タイムラインの背景に、ハイライトとして表示されます。
背景は光っているのに記録のブロックがない時間帯、それが入力し忘れた作業時間です。
あとはその時間帯に、タイムラインから記録を足すだけです。

![1か月分の記録の背景にPCのアクティブ時間帯を重ねて表示する月間タイムライン](/images/73b8af31b1e854/timeline.png)

自動記録で計測忘れを埋める発想自体は、Toggl Track や Timing にもあります。
ただし、どれも「どのアプリで何をしていたか」まで記録する方式です。
TimeTracker が記録するのは「いつ PC を使っていたか」だけです。
アプリ名もウィンドウタイトルも一切記録しないので、特別な権限も必要ありません。

ちなみに、月単位で俯瞰できるタイムライン自体も、調べた範囲では他のツールにありませんでした。
日や週のカレンダー表示は定番ですが、月になるとグラフや表に切り替わるものが大半です。

## データの扱いについて

常駐して時間を記録するアプリは、何を取得しているのか気になりますよね。
TimeTracker の記録はすべて Mac の中に保存され、外部へは送信されません。
アイドル検知や PC アクティブ時間の記録も、キーボードやマウスの入力内容は取得しません。
使うのは、最後に操作してからの経過時間だけです。
そのため、アクセシビリティ権限や入力監視権限を求めることもありません。

## インストール

[最新のリリース](https://github.com/HappyOnigiri/TimeTracker/releases/latest)から zip をダウンロードして展開し、`TimeTracker.app` を `/Applications` に移動すれば使えます。

:::message
このアプリは Apple の公証を受けていないため、初回起動時に macOS が起動を止める場合があります。
一度開こうとしたあと、「システム設定 > プライバシーとセキュリティ」の「セキュリティ」欄で「このまま開く」をクリックしてください。
:::

ソースからビルドする場合は、Xcode と XcodeGen が必要です。

```sh
brew install xcodegen
git clone https://github.com/HappyOnigiri/TimeTracker.git
cd TimeTracker
make install
```

## 技術スタックを少しだけ

中身のロジックには踏み込みませんが、構成だけ簡単に紹介します。

- 言語・UI: Swift 6 + SwiftUI（メニューバー常駐は MenuBarExtra）
- データ保存: SwiftData（ローカルのみ）
- プロジェクト管理: XcodeGen + Makefile
